  because Packagist only has v8.2.0-BETA2. Once 8.2.0 is stable, switching to it
  should only mean changing 8.1.* to 8.2.* in composer.json.

  linters pass, all Doctrine mappings load, and composer audit finds no
  advisories. Running the app locally, /, /login and the three API endpoints
  return 200, and the admin pages redirect to login. I didn't log in or test any
  workflow behind authentication. The project has no tests, so PHPUnit ran
  nothing.

  One page fails: /qrcode/ returns a 500 because the QRCODE_DIR environment
  variable isn't defined in any .env file. I didn't change anything related to
  it, so you'll need to add it.

  Dependencies (composer.json)
  - All Symfony packages are now 8.1.*, and the minimum PHP version is 8.4,
    which Symfony 8 requires.
  - Other packages needed new major versions to work with Symfony 8:
    doctrine/dbal 4, doctrine-bundle 3, doctrine-migrations-bundle 4,
    monolog-bundle 4, stimulus-bundle and ux-dropzone/ux-turbo 3, and
    vich/uploader-bundle 3. Your current JS packages work with UX 3 unchanged.
  - Backups of the old composer.json, composer.lock and symfony.lock are in
    /tmp/claude-1002/-var-www-extranet/3b96f2df-144c-4e34-af08-4d9768662a64/scra
    tchpad/.

  Code fixed because Symfony 8 removed things it used
  - Module config files: the twig.php, doctrine.php, security.php and
    rate_limiter.php files used the fluent Symfony\Config\*Config classes, which
    no longer exist. I rewrote them as $containerConfigurator->extension('…', 
    [...]) arrays with the same settings.
  - Extranet/config/services.php: a string reference '@…Adapter' no longer
    works, so it now uses service(Adapter::class).
  - LdapExtranet: added the two methods the LDAP interface now requires,

  - Upload and serializer attributes: changed
    Vich\UploaderBundle\Mapping\Annotation to …\Attribute in 5 entity files, and
    the Serializer Annotation\Groups to Attribute\Groups.
  - $request->get() was removed: it now reads $request->request->get() in
    ExerciceController and $request->getPayload() in the EnquetePublique
    authenticator.
  - doctrine.yaml: removed options DoctrineBundle 3 no longer accepts, such as
    use_savepoints and auto_generate_proxy_classes.

  Deprecation cleanup: I removed the mapping alias and
  controller_resolver.auto_mapping options, removed the profiler's
  collect_serializer_data, set liip_imagine.twig.mode: lazy, and fixed two

  from VichUploader itself. I also updated the version numbers in CLAUDE.md.
